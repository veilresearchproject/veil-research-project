**Before it is built, it must first be seen.** VEIL is an independent research initiative working on prototypes, software, and experimental methods. The staffed research center is a **future aspiration** and has not been built, funded, or engineered.

### How to review this draft

Preview source: `future-research-center/dev-v05/index.html`. Unlike the downloadable ZIP, this GitHub staging HTML uses the existing parent `../assets/` concept artworks. The main public GitHub Pages site is **unchanged** until explicit release approval.

- Click **Explore the 3D Research Center**, or start the guided stops. Use W/A/S/D, drag to look, Shift to move faster. Mobile has movement controls.
- Go to the east staircase near x = 27.7 in the ground floor reception area and climb to the second-floor command overlook. E jumps upstairs and Q jumps to the main hall.
- The connected loading/workshop openings are real in the 3D model, and physical collisions limit movement through major furniture and walls.
- 13 stops and 1,129 3D objects across 161 geometry categories. Geometry is original low/mid-poly modeled boxes, not photoreal interior captures.
