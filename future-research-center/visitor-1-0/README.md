# VEIL Research Center — Visitor Edition 1.0

**A Vision Taking Shape.** An offline-friendly, interactive 3D architectural *concept* of the proposed VEIL Research Center. The physical facility **does not exist**. These buildings are not engineering drawings and the virtual instruments do not display live data.

## Open the finished visitor edition

- **Best option:** Open `VEIL_Research_Center_Visitor_1_0_SINGLE_FILE.html` in Google Chrome or Microsoft Edge. This contains all six concept illustrations and scene geometry in one HTML file. No installation, subscription, account, server or API key is needed.
- **Editable project:** Unzip `VEIL_Research_Center_Visitor_1_0_COMPLETE.zip` and open `future-research-center/index.html` locally. Edit the companion JSON geometry, or import the static GLB into 3D software.

## Visitor experience

1. Select **Explore the 3D Research Center** to enter the clean, immersive viewing mode.
2. Choose **Next** or **Previous** to visit 13 guided locations, or open **Locations** to jump anywhere. The guided route auto-advances.
3. Choose **Info** at any stop for a concise explanation of the proposed experiment or role.
4. **Roof** and **Section** expose different layers of *actual modeled geometry*, not static concept images. **Lighting** switches day/lab-night. **Focus view** hides the side panels; all can be restored.
5. On desktop use W/A/S/D to walk, drag to look, shift to accelerate, **F** focus, **C** section, **R** roof, **H** help, **I** info, **N/P** next/previous. On touch screens, swipe the scene, use movement arrows and the Locations drawer.
6. **Concept gallery** displays separate aspirational artwork, labeled as distinct from 3D model views.

## Fidelity and release status

The **visitor software flow is complete for this edition**: orientation, 13 stops, movement, scene toggles, explanatory exhibits, responsive controls, standalone offline packaging, and descriptive release documentation. The **model is stylized architectural geometry** and is **not photorealistic**; matching prior high-end concept renderings would require a separate professional 3D modeling/material/lighting effort. Browser software renderer QA passes. True GPU/WebGL rendering and physical Samsung Galaxy S25 touch/performance still require user hardware review. No structural/code/ADA engineering assessment has been performed.

**No changes have been deployed to the VEIL website or posted to Facebook.** A separate owner approval is needed before publication; all staged source is on an isolated GitHub draft branch.
