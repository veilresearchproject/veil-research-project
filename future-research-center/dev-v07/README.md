# VEIL Research Center — A Vision Taking Shape

## Development v0.7.0 • October 29, 2026

**Before it is built, it must first be seen.**

This is a proposed future research center, not a built or operational facility. VEIL currently develops research methods, software and prototypes. This project visualizes a longer-term aspiration.

### Open

1. Extract ZIP while preserving `future-research-center/assets`.
2. Open `future-research-center/index.html` in a current Chrome or Edge browser.
3. Select **Explore in 3D**. Move via W/A/S/D, drag to look, Shift to move faster, or use touch controls on mobile.
4. Click the 13 guided tour stops. **Lighting: Day / Lab night** changes illumination; switch floors using the sidebar or walk the staircase.
5. Open **Concept gallery** for *separately labeled artistic reference images*. These images are NOT screenshots of the modeled environment.

### v0.7 improvements

- Eight world-positioned fixture lights with spatial falloff, warm daylight / cool evening lighting, and soft floor-contact shadows around eight main exhibit footprints in the WebGL renderer.
- More physical ceiling diffuser/rail fixtures, MTC sound panels, workshop conduits and approach markings (**not photographic background swaps**).
- Material-aware specular highlights on steel/glass, procedural concrete texture, night-emissive signage, and gentle filmic exposure mapping. These remain stylized shader approximations rather than physically accurate reflections or ray tracing.
- Guided camera pan now yields to manual walking/dragging; browser performance reduces pixel ratio on narrow/mobile viewports.
- Open editable `VEIL_Research_Center_v07_geometry.json` and GLB exports. Offline runtime still needs no paid service, keys or external JavaScript dependency.
