# GEO-001 — Geographic and Proposed Ley-Line Correlation Study

**VEIL Research Project** · Founder/Lead Researcher: Andrew Underwood  
**Status:** Approved as an *exploratory background-check protocol* on 2026-11-21; no empirical findings yet.  
**Version:** 0.1 · **Date:** 2026-11-21 · **Study owner:** VEIL Research Project

## Purpose and boundary

For each location-based event review or investigation, document whether its coordinates lie near a *previously published proposed ley-line alignment*, alongside conventional geographical and environmental factors. A mapped line is a **claim**, not an independently established energy pathway. Proximity is **not** evidence of a paranormal cause. The result can be “not assessed,” “no identified mapped alignment,” or “proposed alignment identified”; it must not become a paranormal-evidence score.

This protocol is designed to work with VEIL's image/video provenance, synchronized sensor data, uncertainty and chain-of-custody practices. It does not claim that any event site has been checked already.

## Routine site background check

1. **Case identity and privacy:** Assign a case ID, event time/time zone, approximate public location, and a private precise-coordinate record where consent and safety warrant it. Never publish a residential address or precise coordinates without authorization.
2. **Location quality:** Document coordinate source (GPS, verified map point, witness recollection), coordinate reference system (WGS84 when available), estimated horizontal accuracy, and the distinction between *event position* and *building/site centroid*. If uncertain, report a range rather than false precision.
3. **Source-lock the line:** Before outcome analysis, record map/author, URL or archival citation, version or capture date, publication date if known, digitization method, named alignment, intended point/line geometry, and uncertainty. Preserve a local screenshot/export when copyright and permission permit. Do not draw a line through the target event to create post-hoc support. Distinguish historical routes, claims of sacred alignments, and supernatural-energy claims.
4. **Measure distance:** With a documented GIS method and suitable projection or geodesic calculation, measure minimum distance from case location to the *pre-specified* line; record meters, location accuracy, line-digitization uncertainty, and whether the value falls inside the chosen exploratory buffer. No universal “on a ley line” definition exists.
5. **Independent ordinary factors:** Document bedrock and known fault mapping, topography, waterways/groundwater where available, cultural/historic sites, structures, utilities and electrical infrastructure, geomagnetic regional information, plus instrument-measured EMF/magnetic, audio, temperature, humidity, lighting and weather only if actually collected. Keep map-derived geological data separate from onsite instrument measurements.
6. **Event and provenance:** Log report source, original files/device IDs, timestamps and time zones, custody, synchronized sensor links, independent witnesses, site reputation and when witnesses learned it, observation and non-event windows, ordinary explanations and any limitations.
7. **Conclusion:** Mark only a descriptive geographic result and uncertainty. Do **not** infer causation, extraordinary energy, or an increase in paranormal activity from a single location.

## Pilot comparison design (future; not yet executed)

**Research question:** Are independently documented event sites closer to *pre-selected* proposed alignments than appropriate non-event comparison sites, beyond chance and geographic confounders?

- Pre-register one map dataset/line-generation rule, geographic bounds, spatial buffer(s), sample inclusion/exclusion criteria, primary distance measure and statistical analysis **before** looking at group outcomes.
- Select comparison locations from the same accessible region and at comparable levels of settlement, historic-site density, building age/use, tourism, public accessibility and reporting exposure. Record selection procedure and non-events; avoid choosing only well-known haunted places.
- Run a negative control with random or spatially shifted/rotated line networks preserving relevant geometry and density; explore sensitivity to map source, buffer width, and location uncertainty.
- Evaluate spatial clustering and non-independence (e.g., multiple reports from one building), map sampling bias and multiple-testing risks. Do not report descriptive differences as statistically significant unless planned analysis supports it.
- Distinguish three questions: (a) are alignments deliberately constructed in historic landscapes? (b) do claimed alignments match measurable geological/environmental features? (c) do independent event reports cluster there? Evidence for one question does not establish another.
- Test proposed environmental mechanisms using calibrated sensors and controls, not ley-line proximity as their surrogate. Document instrument drift, mains wiring, electronics, weather and human activity.
- Publish negative and inconclusive findings, with privacy-safe case data and explicit analysis provenance. Seek external method review before claims of correlation.

**Pilot thresholds:** To be established in a dated, pre-registered analysis plan once a particular geographic region and ley-line dataset have been selected. Do not retroactively choose distance thresholds from findings.

## Reporting language

- **Not assessed:** insufficient coordinate reliability or no vetted line dataset.
- **No identified mapped alignment within the pre-set buffer:** only for the specified map, region, threshold and uncertainty.
- **Proposed alignment identified within the pre-set buffer:** geographic description only; include map and uncertainty.
- **Comparative association observed / not detected / inconclusive:** reserved for a pre-specified multi-site analysis, *never* for one case.

Avoid “confirmed ley line,” “energy hotspot,” “paranormal correlation” or “no ley lines exist” as conclusions from a map lookup.

## Integration and safeguards

- Add “GEO-001 completed? yes/no/not possible” to future internal case intake and evidence reviews. Record source and status; skip detailed analysis when the location is unknown or privacy-protected.
- New case records start as **not assessed** until data and line provenance are available. Do not backfill a positive or negative answer without a documented review.
- Keep a dated change log for map dataset replacement, parameter revisions, analyst review and corrected coordinates. Preserve prior results rather than silently overwriting.
- This file is a **research protocol**, not published results, peer review, approval by an institution, or evidence of an operating ley-line detection device.
