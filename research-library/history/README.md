## Interpretation

Verification is claim-specific. A Sent message verifies sending, not delivery, acceptance or publication. A live post verifies visible content, not scientific accuracy or original posting time. Missing data stays null. A missing reply is neither rejection nor proof of continued editorial consideration.

This repository is public. Private correspondence, unpublished manuscripts, private-group material and nonpublic personal activity remain in restricted original sources. Only suitable summaries and source identifiers appear here. This is an index and partial text archive, not a complete backup of those originals.
