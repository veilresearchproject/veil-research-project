Privacy & honesty: Scripted mode makes no requests. When you explicitly enable local AI, this page sends typed questions and recent chat context only to a Python server on 127.0.0.1, which contacts Ollama on the same machine. Nothing is sent to a cloud service by SIGNAL; a separately installed Ollama model is required. Conversations stay in this tab's memory, are never saved by the app, and disappear when cleared or closed. No microphone, camera, autonomous actions, evidence analysis, or live instruments. AI-generated replies can be wrong; always verify research claims. Device text-to-speech may use an online voice.
