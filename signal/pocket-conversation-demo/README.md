SIGNAL Pocket Conversation Lab v0.1 — November 2, 2026

SCOPE
A static, single-file, offline-first, rule-based interactive demonstration for mobile and desktop. It can respond to typed prompts about VEIL, MTC, evidence, sensors, Panic Box, privacy, and jokes. It has simple within-tab topic follow-ups and an opt-in Speak button using the browser's device speech synthesis. The demo is NOT a conversational LLM, microphone-enabled assistant, lab instrument control system, sentient AI, or evidence validator.

OPEN
Save SIGNAL_Pocket_Conversation_v0.1.html to your computer or phone and open it in a browser. If your phone cannot open local HTML attachments, use a desktop browser or a trusted local file viewer instead. Voice support and offline TTS depend on the device/browser. No network calls are initiated by page code. No cloud subscription or API keys are required.

TESTS
18 of 18 dependency-free Node tests passed using browser/speech mocks.
Chromium mobile emulation at 390 x 844 passed: prompt buttons, typed entry, clear/reset, no JavaScript page errors, no outbound requests.
Actual Samsung S25 voice output and on-device user acceptance testing have NOT been performed.

CAUTION
No input or transcript is stored, but it remains visible in the browser while the page is open. Clear removes visible messages. Avoid private information in any experimental demo. Device speech synthesis may use online voices; no offline TTS guarantee.
