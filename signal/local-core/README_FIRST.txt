VEIL SIGNAL DESKTOP v0.16 — START HERE

Extract the entire ZIP into a NEW folder. Keep earlier folders as fallbacks.
Double-click START_HERE.bat. Python 3.10+ with its launcher is required.

The package is checked, then you choose:
  1  Scripted face demo (no AI model)
  2  Live assistant (start local Ollama first)
  3  Local setup check (no speaking or microphone capture)
  4  Automated tests (simulated model/audio)
  5  Read the desktop test steps
  Q  Quit

Nothing installs or downloads. Voice and microphone start OFF. Reopen START_HERE
when you want another menu option. Existing launch scripts are also included.

The package check detects missing or changed files; it does not prove authenticity
or test real hardware. If a check fails, extract a fresh copy into a new folder.
Original MTC recordings and saved conversations are not altered by this launcher.
