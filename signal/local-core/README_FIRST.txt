VEIL SIGNAL Desktop Face Alpha v0.4
=================================

1. Extract ALL ZIP files to a normal Windows folder.
2. Double-click START_SIGNAL_FACE_DEMO.bat to view SIGNAL's face and try the
   interface WITHOUT needing Ollama. This mode uses clearly labeled SCRIPTED replies.
3. After installing/starting local Ollama, double-click START_SIGNAL_DESKTOP.bat
   for real local AI conversation, then optionally click Enable voice.
4. Paste your MTC session folder into the "Load a local MTC evidence log" control.

Everything stays local; no paid API, no microphone and no device-control functions.
The live Ollama model and Windows audio need checking on your actual PC.
See SIGNAL_DESKTOP_README.md for complete instructions.
